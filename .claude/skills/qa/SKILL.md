# QA 체크리스트

**자동 테스트가 전부 통과해도 사람이 눌러야만 나오는 결함이 있다.**

공지 게시판 작업에서 결함 6건이 전부 이 경로로만 나왔다. 그때 테스트는 322건 그린이었다.

| 결함 | 테스트가 못 잡은 이유 |
| --- | --- |
| 첨부 버튼 미노출 | 요소는 DOM에 있다. 화면 밖에 있을 뿐 |
| 사진과 글자 겹침 | 레이아웃은 검증 대상이 아니었다 |
| 사진 2장 가로 배치 | 위와 동일 |
| 배경 확대 | 위와 동일 |
| 목록 발췌가 붙음 | N+1 스펙은 **쿼리 수만** 봤다 |
| 제목 미반영 | **코드 문제가 아니었다** (서버 재시작 누락) |

## 언제 도나

`dev-flow` ⑤-c 워크스루 다음, **⑥ 커밋 앞**이다.

| 왜 검증 뒤인가 | 테스트가 통과한 뒤라 **동작하는 화면**을 본다 |
| --- | --- |
| **왜 커밋 앞인가** | 수정이 별도 커밋이나 amend로 번지지 않는다 |

## 맨 위에 고정으로 넣는 줄

```
[ ] 마이그레이션이 포함됐다면 — 서버를 재시작했는가
```

이 줄이 없어서 **코드 문제가 아닌 것을 버그로 오인**한 적이 있다. 세 층위(모델·요청·브라우저)를 전부 재현한 뒤에야 원인이 드러났다.

## 항목을 뽑는 기준

변경한 파일에서 역산한다. **바꾸지 않은 화면은 넣지 않는다** — 목록이 길면 안 누른다.

| 변경 종류 | 뽑을 것 |
| --- | --- |
| 마이그레이션 | 서버 재시작 / **기존 데이터가 그대로 보이는가** |
| 뷰·CSS | 모바일 폭 / 데스크톱 폭 / 긴 입력 / 빈 상태 |
| 폼 | 필수값 비우고 저장 / **수정 화면에 기존값이 떠 있는가** |
| 목록 | **사람이 읽을 수 있게 나오는가** (붙지 않았는가, 잘렸는가) |
| 권한 | 비로그인 / 타인 글 / Admin |
| 업로드·외부 연동 | **운영에서만 확인 가능한 것**을 따로 표시 |
| 삭제 | 확인 모달 / 삭제 후 이동 |

### 특히 챙길 것

**겹침과 잘림.** 요소가 존재하는 것과 보이는 것은 다르다. 가로 스크롤에 가려지거나 다른 요소에 덮이는지 본다.

**빈 상태.** 데이터가 0건일 때 화면이 깨지지 않는가.

**긴 입력.** 제목 100자, 본문 여러 문단, 사진 여러 장.

## 출력 형식

화면 단위로 묶는다. 어디로 가서 무엇을 누르는지 **순서대로** 쓴다.

```
공지 목록
  [ ] 제목을 누르면 상세로 가는가
  [ ] "사진 N장" 배지가 사진 있는 글에만 뜨는가
  [ ] 발췌가 2줄에서 잘리는가

공지 작성
  [ ] 제목 비우고 저장 → "제목을 입력해주세요."
  [ ] 이미지 첨부 → 미리보기가 뜨는가
  [ ] 모바일 폭에서 툴바가 깨지지 않는가
```

**운영에서만 확인 가능한 것은 따로 표시한다.**

```
배포 후에만 확인 가능
  [ ] 이미지 첨부 (개발은 Disk 서비스라 CSP를 타지 않는다)
```

## 결함이 나오면

⑤ 검증으로 **돌아간다.** 고치고 CI 6개 명령을 전부 다시 돌린 뒤 QA도 다시 한다.

**왜 자동 테스트가 못 잡았는지** 한 줄 적는다. 테스트로 덮을 수 있는 종류면 스펙을 추가하고, 아니면 왜 못 덮는지 적는다. 그게 다음 QA 항목의 근거가 된다.

## 하지 않을 것

**Claude가 대신 눌렀다고 하지 않는다.** 스크린샷으로 확인할 수 있는 건 확인하고 그렇게 말하지만, **실기기 터치·Windows Chrome·운영 환경은 대신할 수 없다.**

**체크를 대신 채우지 않는다.** 사용자가 누르고 사용자가 채운다.

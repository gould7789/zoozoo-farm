# 주주팜 — 도메인과 언어

## 이 서비스는 누가 쓰나

실제로 운영 중인 **한국의 동물원**에서 사육사가 쓴다. 직원 10명 미만.

도입 전에는 기록이 종이·엑셀·카카오톡 세 곳에 흩어져 있었고 각각 다른 이유로 실패했다.

| 수단 | 왜 실패했나 |
| --- | --- |
| 종이 | 현장에서 과거를 못 본다. 분실되고 검색이 안 된다 |
| 엑셀 | 동시 편집으로 파일이 갈라지고, 모바일에서 못 쓴다 |
| 카카오톡 | 흘러간다. 무엇에 대한 공지인지 남지 않는다 |

현장에서 **우리(Cage) 앞에 서서 스마트폰으로** 쓰는 것이 기본 시나리오다.

> **「직원 10명 미만」은 설계 판단의 근거로 계속 쓰인다.** Puma 스레드 3개, CDN 미도입, 고아 blob 방치가 전부 이 숫자에서 나왔다. 규모를 모르면 과한 설계를 하게 된다.

## 설명 문서 지도

**코드를 고치기 전에 그 파일이 어느 노트에 걸려 있는지 본다.** 각 코드 파일 맨 위에도 같은 포인터가 있다.

| 노트 | 무엇이 들어 있나 | 어느 코드 |
| --- | --- | --- |
| `notes/notice.md` | 리치텍스트 이름 충돌, 2단계 이관, CSP, 발췌, 임베드 검증 | `notice.rb`, `notices_controller`, `views/notices`, 이관 마이그레이션 |
| `notes/auth.md` | 이메일 기준 rate limit, `reset_session` 순서, 마지막 관리자 보호 | `sessions_controller`, `application_controller`, `admin/users_controller`, `user.rb` |
| `notes/animal-photo.md` | HEIC·libvips, `purge` vs `purge_later`, 검증 에러 때 사진 | `animal.rb`, `animal_photos_controller`, 사진 JS 2개 |
| `notes/xlsx-export.md` | Excel `####`, 서식 코드, 고정 행, 분류 칸 비우기 | 내보내기 컨트롤러 5개 + base |

`common/` 은 레이어 축(지킬 규칙), `notes/` 는 도메인 축(왜 이렇게 생겼나)이다. **축을 섞지 않는다.**

더 두꺼운 설명은 `docs/` 에 있다 — `active-storage.md`(이미지 파이프라인 336줄), `ai-workflow.md`.

## 언어

| 대상 | 언어 |
| --- | --- |
| 코드 (변수·메서드·클래스명) | **영어** |
| 그 외 전부 (주석·테스트 문자열·화면 텍스트) | **한국어** |

화면 텍스트가 한국어인 이유는 **쓰는 사람이 한국 동물원 직원**이기 때문이다. 현장 직원이 읽지 못하면 기능이 없는 것과 같다.

주석은 **코드를 되풀이하지 않는다.** 남기는 기준은 「이 줄을 지우면 다음 사람이 같은 함정에 빠지는가」다. 설계 근거와 알아두면 좋은 문법만 남기고, 두 줄로 안 되는 분량은 `notes/` 로 뺀다.

`README.md` 는 일본어다 — 읽는 사람이 다르다.

## 권한

```ruby
enum :role, { admin: 0, staff: 1 }
```

| 역할 | 대상 | 권한 |
| --- | --- | --- |
| `admin` | 정직원 사육사 | 전체 CRUD + 계정 관리 + 감사 대응 |
| `staff` | 아르바이트 사육사 | 기록 추가 + **본인 기록만** 수정·삭제 |

**회원가입 페이지가 없다.** Admin이 Staff 계정을 만들어 전달한다. 퇴사는 `active = false` 논리 삭제이고 실제 DELETE를 하지 않는다 — 감사 추적을 보존해야 한다.

`current_user`가 매 요청 `User.active`를 다시 조회하므로, **퇴사 처리는 기존 세션에도 즉시 듣는다.**

## 위협 모델

네트워크 경계가 없다. 현장에서 LTE로 쓰므로 VPN도 IP 허용목록도 맞지 않는다. **인증과 인가가 전부**다.

현실적으로 일어나는 일은 외부 공격자가 아니다.

```
가능성 높음   퇴사자가 예전 링크로 접근
가능성 높음   직원이 URL을 단톡방에 붙여넣어 외부로 흘러감
가능성 높음   사무실 공용 PC에 로그인 상태 방치
가능성 낮음   외부 공격자가 노리고 들어옴
```

**작정하고 재직 중에 자료를 들고 나간 사람은 어떤 설정으로도 막을 수 없다.** 막는 것은 사고로 새는 경로다. 권한을 역할로 나눈 것도 같은 판단이다 — 가져갈 수 있는 것과 **망칠 수 있는 것**을 분리했다.
